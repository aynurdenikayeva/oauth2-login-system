# OAuth2 Login System

This project demonstrates a production-style OAuth2 authentication system built with Spring Boot and Spring Security.

Users can log in using:
- Google OAuth2
- GitHub OAuth2

After successful authentication, the application:
- retrieves user profile information
- stores the user in the database (PostgreSQL)
- generates a JWT token for secure API access.
